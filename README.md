# 🏆 Esportes na Tela

Sistema automatizado de agenda esportiva com IA - Gere cards premium para redes sociais com busca automática via Gemini.

## 🚀 Tecnologias
- HTML5 + CSS3
- JavaScript ES6+
- Google Gemini API
- html2canvas

## 📋 Funcionalidades
- 🤖 Busca automática com IA (F1, NBA, UFC, Futebol, NFL, MotoGP)
- 🎴 Cards premium com temas dinâmicos
- 📝 6 formatos de texto para redes sociais
- 📥 Exportação em PNG alta resolução
- 📺 Filtros por tipo de canal

## 🔧 Como usar
1. Obtenha uma chave da API Gemini no [Google AI Studio](https://aistudio.google.com/)
2. Cole no campo "Chave da API Gemini"
3. Clique em "Salvar" e depois em "Buscar com IA"
4. Edite os eventos se necessário
5. Gere os cards e compartilhe!
